# keizu 系図

Government power-relations actor: public-role nodes and sourced committee, money,
statement, and relation edges are woven into an aggregate-first accountability map.
It records disclosed facts and never produces guilt, influence, or person scores.

Canonical repository data and contracts are EDN:

- `manifest.edn`, `identity.edn`, `dependencies.edn`
- `schema/government-relations-ontology.kotoba.edn`
- `registry/sources.seed.edn`
- `data/seed-relation-graph.kotoba.edn`

Source lives under `src/keizu`; tests live under `test/keizu`.
Run the complete portable suite with `bb run_tests.clj`.
